 # 🏆 Sportify – Sports Tournament Management Portal

Sportify is a modern and user-friendly **Sports Tournament Management Portal** built using **React.js**. It provides a centralized platform to manage tournaments, teams, players, matches, and tournament information. The portal includes dedicated dashboards for administrators and players, making sports tournament management simple, organized, and efficient.

## 🚀 Features

- 🏆 Tournament Management
- 👥 Team Management
- 🧑 Player Management
- 📅 Match Information
- 📊 Tournament Dashboard
- 👤 Player Dashboard
- 📱 Responsive User Interface
- 🎨 Modern and Interactive Design

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3

## 🎯 Objective

The main objective of Sportify is to provide a simple digital platform for organizing and managing sports tournaments while making tournament and player information easily accessible.
